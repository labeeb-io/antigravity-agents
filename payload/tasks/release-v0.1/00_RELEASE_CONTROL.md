## 🎯 الموقف التشغيلي الراهن (`WIP = 1`)

> [!IMPORTANT]
> ميثاق v0.1 يبقى مجمداً حول رحلة الاستوديو. قرار 1 أكتوبر يعتمد عملاً محلياً تمهيدياً على خط الاستيعاب قبل استئناف الفحص الحي للاستوديو؛ هذا لا يغيّر نطاق المنتج.

- **رمز المهمة/مسار الإثبات الراهن:** `TASK-BE-DISCOVERY`
- **الاسم:** **استكشاف مسار استيعاب الأخبار والادعاءات محلياً (تمهيد تأسيسي للاستوديو)**
- **المنسق:** `release-coordinator` عبر `/shipping`، ويستدعي `discovery-coordinator` عند الحاجة.
- **الموقف المثبت قبل تحويل نظام الوكلاء:**
  - تم تأجيل التجارب الحية على الاستوديو وفق قرار المؤسس المسجل في 1 أكتوبر.
  - الهدف الراهن هو إثبات مسار الاستيعاب محلياً أو تحديد أول حد فشل مثبت.
- **دليل الإغلاق المطلوب:** دليل Runtime يتوافق مع عقد الاكتشاف الحالي؛ لا يعتبر تحويل نظام الوكلاء دليلاً على نجاح الـPipeline.
